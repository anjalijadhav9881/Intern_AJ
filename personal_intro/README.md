# Week 1: Personal Introduction Program 🚀

A beginner-friendly command-line utility built in Python that collects user details interactively and outputs a formatted welcome message.

##  Project Overview
The goal of this project is to understand the core mechanics of Python programming, including:
* Variable assignment and data types (`str`, `int`)
* Standard input handling using `input()`
* Output formatting via f-strings
* Basic error handling and code structure

1. **Install Python:** Ensure you have Python 3.8+ installed on your system (Download from [python.org](https://www.python.org/)). Alternatively, run the code directly in your browser using [Google Colab](https://colab.research.google.com/).
