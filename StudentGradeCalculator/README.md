# Week 2: Student Grade Calculator 

An intermediate Python command-line utility that computes student grades using structured conditional logic, loops for input validation, and reusable functions.

## Project Overview
The objective of this project is to implement:
* **Conditional Branching:** Using `if-elif-else` structures to categorize marks into letter grades (`A` through `F`).
* **Input Validation & Loops:** Using `while` loops combined with `try-except` blocks to gracefully handle user errors (strings, out-of-range bounds).
* **Modular Code Structure:** Encapsulating specific logic inside modular functions (`calculate_grade`, `get_valid_marks`).

## Setup Instructions
1. Ensure you have Python 3.8+ installed.
2. Clone this repository or download `grade_calculator.py`.
3. Open your terminal in the script directory and execute:
   ```bash
   python grade_calculator.py
